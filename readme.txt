設計理念：
    這份電子辭典的設計核心，是幫助當地年輕人重新學習與使用自己的母語。由於現代化影響，許多年輕人已經不太會講克里奧語，因此我們希望透過數位工具，讓語言能被更方便地學習、保存與傳承。
    整個系統所採用的技術皆為開源工具，目的在於後續能由在地使用者自由推廣、維護與持續開發，確保這份辭典能長久服務社群，而不受技術門檻限制

搜尋介面：
使用者可以輕鬆切換「英語搜尋 Kwéyòl」與「Kwéyòl 搜尋英語」兩種模式。搜尋引擎支援即時查詢，並提供以下功能：
　　精確搜尋：顯示與輸入內容完全相符的詞彙。
　　模糊搜尋：依據相似拼字及字根，提供相關詞彙，幫助使用者探索更多可能。
目前系統已收錄 4,857 個英語至克里奧語的單字，內容經由自動化程式整理後，再進行人工校對。未來將持續擴充資料庫，逐步收錄更多詞彙。
克里奧語至英語的資料庫則仍在建置中，完成後預計可收錄 約 8,000–10,000 個單字，並提供定義、克里奧語例句及其對應的英文翻譯。

資料庫擴充方式
辭典的成長仰賴多種來源：
　　人工蒐集：由團隊持續彙整並校對詞彙。
　　文獻資料：參考既有出版品與語言學研究成果。
　　社群參與：讓使用者透過平台回饋，補充或修正詞彙，如圖四。
其中，社群回饋是最關鍵的方式。我們希望讓使用者不只是查詢者，更是資料庫的共同建設者。
 
側邊欄
側邊欄設計了三個欄位，如圖五：
　　使用說明
　　更新紀錄
　　回饋 (Feedback)
在 Feedback 區塊中，使用者可以提交詞彙建議或修正。我們會進行人工審核，確認正確性後再納入更新。透過這種方式，資料庫能隨時代演進而保持活力與準確性。
 
電腦版與手機版介面
考量到當地使用的手機品牌多樣，為了避免數位落差，我們在設計上選擇了對所有裝置負擔最小的方式：
　　不需要額外安裝 App
　　只需透過網址即可直接使用
　　提供跨裝置一致的體驗，確保所有人都能輕鬆存取辭典
